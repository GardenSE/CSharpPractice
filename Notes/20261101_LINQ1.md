# LINQの引数や戻り値の型を意識する

## LINQ全体
- CountPostCodeFromPrefectures()は、テストデータを生成するローカルメソッド
  
``` CSharp
public void CountPostCodeFromPrefectures()
{
    var result = GeneratePostCodeData()
                    .GroupBy(p => p.PrefectureName)
                    .Select(g => new 
                    {
                        PrefectureName = g.Key, 
                        CountNum = g.Count(),
                    })
                    .Where(p => p.CountNum >= 5)
                    .OrderByDescending(x => x.PrefectureName);
}
```

## .GroupBy
### 引数
- 引数：p => ...
- 型  ：PostCodeModel型（自作クラス）
         →GroupBy に渡している元データが IEnumerable<PostCodeModel> であるため

### 戻り値 
IEnumerable<IGrouping<string, PostCodeModel>

- sring：グループ化するキー（ここでは都道府県名）
- PostCodeModel：グループに格納される要素の型
- 【重要】GroupByが返すのは、IGrouping 1つではなく、複数を格納する IEnumerable

``` CSharp
{System.Linq.Enumerable.GroupByIterator<CSharpPractice.Core.Models.PostCodeModel, string>}
    [0]: Key = "北海道"
    [1]: Key = "大阪府"
    [2]: Key = "埼玉県"
    [3]: Key = "神奈川県"
```

## .Select
### 引数
- 引数：g => new {}...
- 型  ：IGrouping

### 戻り値
- Select のラムダ式の戻り値：匿名型
- Select 全体の戻り値：IEnumerable<匿名型>

``` CSharp
{System.Linq.Enumerable.IteratorSelectIterator<System.Linq.IGrouping<string, CSharpPractice.Core.Models.PostCodeModel>, <>f__AnonymousType0<string, int>>}
    [0]: {{ PrefectureName = 北海道, CountNUm = 7 }}
    [1]: {{ PrefectureName = 大阪府, CountNUm = 1 }}
    [2]: {{ PrefectureName = 埼玉県, CountNUm = 1 }}
    [3]: {{ PrefectureName = 神奈川県, CountNUm = 1 }}
```

### Count()は何を数えているのか？
- 各グループに含まれる PostCodeModel の要素数

## .OrderByDescending
### 引数
- 引数：x => x.PrefectureName
- 型 ：文字列型

### 戻り値

``` CSharp
{System.Linq.Enumerable.OrderedIterator<<>f__AnonymousType0<string, int>, string>}
"{ PrefectureName = 北海道, CountNum = 7 }",北海道,7
"{ PrefectureName = 大阪府, CountNum = 1 }",大阪府,1
"{ PrefectureName = 神奈川県, CountNum = 1 }",神奈川県,1
"{ PrefectureName = 埼玉県, CountNum = 1 }",埼玉県,1
```

### 何を基準に降順で並び替えているのか？
- 匿名型の CountNum プロパティ（int型）を基準に並び替えている

## Where
### 引数
- 引数：p => p.CountNum >= 5
- 戻り値：匿名型

### 戻り値
- ラムダ式の戻り値：bool型
- Whereメソッド全体の戻り値：IEnumerable
``` CSharp
{System.Linq.Enumerable.IEnumerableWhereIterator<<>f__AnonymousType0<string, int>>}
    [0]: {{ PrefectureName = 北海道, CountNum = 7 }}
    [1]: {{ PrefectureName = 青森県, CountNum = 5 }}
```
